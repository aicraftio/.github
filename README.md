# aicraftio/.github

Organization default issue forms for every AICraft repository.

| Form | Use |
| --- | --- |
| Feature request | Shape Up pitch. Track the issue on [Platform features](https://github.com/orgs/aicraftio/projects/1). |
| Bug report | Reproduction steps, expected and actual results, and screenshots. Track the issue on [Bugs and regressions](https://github.com/orgs/aicraftio/projects/2). |

Files live in `.github/ISSUE_TEMPLATE/`. Agents file the same sections with `/request-feature` and `/raise-bug` because `gh issue create` does not apply these forms.

Do not put product code in this repository.
